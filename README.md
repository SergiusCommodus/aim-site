# AIM | Artemis Investment Metrics

Marketing site for AIM, a decision intelligence platform for real estate, small business acquisitions, and personal finance. A product of Carlisle Capital LLC.

## What is here
* `index.html` is the whole site: one self contained page with inline CSS and JS, fonts from Google Fonts.
* The hero includes a working long term rental analyzer (cash flow, cap rate, cash on cash, DSCR, target price for 1.25 DSCR).

## Hosting on GitHub Pages
Settings, then Pages, then Source: Deploy from a branch, Branch: `main`, folder `/ (root)`.

## Beta signups
The beta form is not connected yet. Create a form endpoint (for example Formspree) and set `FORM_ENDPOINT` in the script near the bottom of `index.html`.
